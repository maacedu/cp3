
# Aula 06 — APIs Web com Flask

## Objetivo

Desenvolver APIs para gerenciamento de alertas,
usuarios, analise de senhas e verificacao de IPs.

## Ambiente

- Python
- Visual Studio Code
- Flask
- Requests

## Instalacao

Criar ambiente virtual:

    py -m venv .venv

Ativar:

    .\.venv\Scripts\Activate.ps1

Instalar dependencias:

    pip install -r requirements.txt

## Arquivos

- app.py
- exercicio_6_1.py
- exercicio_6_2.py
- exercicio_6_3.py
- testar_api.py

## Portas utilizadas

- API principal: 5000
- API de usuarios: 5001
- API de senhas: 5002
- API de IPs: 5003

## Conceitos estudados

- APIs Web
- Flask
- HTTP
- GET
- POST
- PUT
- DELETE
- JSON
- Rotas
- Validacao de dados
- Status codes
- Tratamento de erros

## Conclusao

A aula apresentou o desenvolvimento de APIs com Python
utilizando Flask, permitindo que sistemas diferentes
se comuniquem por meio de requisicoes HTTP.
