
# Aula 04 — Machine Learning para Segurança

## Objetivo

Utilizar Machine Learning para identificar tráfego malicioso,
detectar phishing e encontrar comportamentos anormais.

## Ambiente utilizado

- Python
- Visual Studio Code
- NumPy
- Scikit-learn

## Instalação

Criar ambiente virtual:

    py -m venv .venv

Ativar ambiente:

    .\.venv\Scripts\Activate.ps1

Instalar dependências:

    pip install -r requirements.txt

## Bibliotecas

- NumPy: organização e manipulação dos dados.
- Scikit-learn: treinamento e avaliação dos modelos.

## Arquivos desenvolvidos

- classificacao_trafego.py
- deteccao_anomalias.py
- exercicio_4_1.py
- exercicio_4_2.py
- exercicio_4_3.py

## Conceitos estudados

- Machine Learning supervisionado.
- Machine Learning não supervisionado.
- Random Forest.
- Isolation Forest.
- Acurácia.
- Precisão.
- Recall.
- F1-score.
- Matriz de confusão.

## Conclusão

O Machine Learning pode auxiliar na identificação de ameaças
e comportamentos suspeitos em ambientes de segurança.

Os resultados dos modelos devem ser analisados por profissionais,
pois previsões podem conter erros.
